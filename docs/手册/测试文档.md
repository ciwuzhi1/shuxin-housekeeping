## 第一部分：自动化测试（pytest，26 项）

```bash
cd 家政
```

### 已知局限

1. 不覆盖前端 UI 渲染（依赖手工清单）；
2. 不含 MySQL 故障注入/连接池压力测试；
3. 密码为 SHA-256 + 固定盐（简单方案），未采用 bcrypt/scrypt 慢哈希；
4. 提现/拒单/禁用/认证上传等演示占位（README「已知问题」中注明为有意保留）无后端流转，未纳入自动化断言。

## 第三部分：测试覆盖缺口（后续可补充）

| 缺口 | 建议 |
|------|------|
| 前端组件/UI 测试 | 引入 vitest + Testing Library，覆盖关键页面渲染与交互 |
| 数据库故障注入 | 断连/超时场景断言 5xx 与降级行为 |
| 慢哈希升级 | 密码从 SHA-256 + 固定盐升级为 bcrypt/argon2（若上线） |
| 并发/压力 | locust 对订单创建/接单做基础压测 |
