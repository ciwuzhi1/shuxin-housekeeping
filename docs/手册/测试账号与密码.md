## 三、登录方式

1. **方式一（推荐）**：点击登录页角色卡片 → 自动选中角色并预填账号密码（**不会自动登录**）→ 点击「登录」按钮确认后进入对应端。
2. **方式二**：选好角色 → 输入用户名与正确密码 → 点击登录。

> 缓冲设计：角色卡片只负责「选角色 + 预填账号」，需再点「登录」才真正进入，避免误触卡片直接跳入家政端/管理端。

## 四、登录失败排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 红色「登录失败」 | 密码错误（或用户名不属于所选角色） | 检查密码与角色是否匹配上表 |
| 红色「登录失败」 | 后端未启动 | 启动后端（见《启动说明.md》）后重试 |
| 页面底部黄色「后端未启动」 | 后端未运行，降级到 Mock | 启动后端即可恢复真实数据 |
| 错误提示「密码错误」 | 输入了错误密码 | 使用上表正确密码 |

> 注：页面降级到 Mock 数据时（后端未启动），Mock 登录不校验密码，仅用于离线演示。

## 五、注册说明（v3.5 起）

| 场景 | 行为 |
|------|------|
| 注册「用户 / 家政人员」 | 提交后由后端校验（用户名唯一、手机号格式），成功提示后跳转登录 |
| 重复用户名 / 手机号格式错误 | 后端返回明确错误提示（不再伪装"注册成功"） |
| 注册「管理员」 | 前端无入口；直接调接口也会被后端拒绝（400/422） |
| 后端未启动 | 离线演示降级：提示"注册成功（数据未保存，演示模式）" |
